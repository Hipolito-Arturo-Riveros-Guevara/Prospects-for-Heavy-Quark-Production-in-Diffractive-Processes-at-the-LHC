# Prospects-for-Heavy-Quark-Production-in-Diffractive-Processes-at-the-LHC

We present an analysis of the prospects for the Large Hadron Collider (LHC) for measurements of charm, bottom and top production in inclusive interactions in photon - photon collisions, described within perturbative Quantum Chromodynamics (pQCD), using Monte Carlo generators such as Pythia 8. We calculate cross sections for different Pythia 8 main settings for diffractive processes in order to obtain estimations for charm and bottom production with one leading intact proton. We explore the simulation of single diffractive interactions with Pythia 8, analyzing key features and the impact on kinematic distributions to better understand the system evolution. We probe the pomeron remnants contribution by constraining the rapidity of the hard subprocess ( $$b\bar{b}$$ ).  Finally, we present the prospects for the photon - pomeron exchange inside the heavy quark production framework for a central and forward region.
We consider total cross section for a center of mass energy 13 TeV for $$c\bar{c}$$ and $$b\bar{b}$$. We run the simulation in Pythia 8 to understand the impact of different settings. We focus on checking the effects of multiple parton interactions in simulation as well as choosing different Pomset settings.
